Run Java JAR Files on Android with Jre4Android

Jre4Android is a Java runtime tool for Android that helps you run JAR files, CLASS files, Java command-line programs, Swing GUI apps, and J2ME apps directly on your Android device.

What is Jre4Android?

Jre4Android lets Android users run Java applications without a desktop computer. You can open a JAR file, run command-line Java programs, launch Java Swing GUI apps, and test simple Java tools on your phone.

Key Features

  • Run JAR files on Android
  • Run .class files
  • Java command-line mode
  • Java Swing GUI support
  • J2ME app support
  • Custom arguments support in Pro version
  • Java 17 support in free version
  • Java 25 support in Pro version

How to Run a JAR File on Android

  1. Download and install Jre4Android from Google Play.
  2. Open the app.
  3. Tap Open JAR File.
  4. Select your .jar file.
  5. Tap Run.
  6. View the output in the terminal or GUI window.

How to Run a CLASS File

  1. Open Jre4Android.
  2. Select CLASS mode.
  3. Choose your compiled .class file.
  4. Run the class file on your Android device.

How to Run Java Swing Apps on Android

Jre4Android supports running many Java Swing GUI applications on Android. You can launch desktop-style Java GUI apps and interact with them using touch controls, virtual mouse, zoom, and keyboard input.

How to Run J2ME Apps

Jre4Android also supports J2ME apps by integrating J2ME-related runtime support. This is useful for running classic Java mobile apps and games.

Common Problems

The JAR file does not start

Some JAR files do not include a Main-Class entry in META-INF/MANIFEST.MF. In this case, you can use Jar File Opener to inspect the manifest file.

Swing app does not display correctly

Some Java desktop apps may require additional libraries or desktop-specific features. Try using zoom, move, virtual mouse, or keyboard controls.

Java version mismatch

Some JAR files require a specific Java version. Check whether the JAR requires Java 8, Java 17, Java 21, or Java 25.
